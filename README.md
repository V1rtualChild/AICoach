# AICoach — Персональний ШІ-тренер та порадник з харчування

> Мобільний застосунок, що генерує індивідуальні тренувальні плани та рекомендації з харчування на основі антропометричних даних користувача з використанням великої мовної моделі LLaMA 3.3 70B.

## Загальна інформація

- **Тип проєкту**: Мобільний застосунок (iOS / Android)
- **Мова програмування**: JavaScript (JSX)
- **Фреймворки / Бібліотеки**:
  - React Native
  - Expo
  - React Navigation
  - AsyncStorage
  - Axios
- **Зовнішні API**:
  - Groq API (LLaMA 3.3 70B) — генерація тренувань та аналіз харчування
- **Призначення**: AICoach розроблений для людей, які прагнуть вести активний спосіб життя та отримувати персоналізовані тренувальні плани і рекомендації з харчування без необхідності звертатись до персонального тренера.
- **Цільова аудиторія**: люди будь-якого рівня фізичної підготовки, які бажають тренуватись вдома або в залі.
- **Унікальність проєкту**: AICoach поєднує генерацію тренувань через LLM, 8-тижневу програму періодизації, динамічну адаптацію навантаження на основі щотижневого звіту та аналіз харчування через ШІ в єдиному безкоштовному мобільному застосунку.

## Опис функціоналу

### Екран налаштувань (Setup)
- Введення антропометричних даних: вік, вага, зріст
- Вибір статі, фітнес-цілі, місця тренувань, рівня активності та типу харчування

### Головний екран (Home)
- Відображення поточного тижня програми
- Швидкий доступ до генерації тренування, історії та аналітики

### Екран тренування (Workout)
- Відображення згенерованого ШІ плану тренування
- Список вправ із деталями: підходи, повторення, поради, YouTube пошук
- Відмічання виконаних вправ
- Оцінка складності тренування (легко / добре / важко)
- Рекомендація страви після тренування

### Екран історії (History)
- Перегляд усіх попередніх тренувань у хронологічному порядку
- Розгортання деталей кожного тренування

### Екран прогресу (Progress)
- Відображення поточної ваги та ІМТ
- Динаміка змін ваги відносно початкових показників
- Об'єми тіла: шия, груди, біцепс, талія, сідниці, стегно, ікри

## Як запустити проєкт "з нуля"

### 1. Встановлення інструментів

- Node.js v18+
- npm v9+
- Expo CLI:
```bash
npm install -g expo-cli
```
- Застосунок **Expo Go** на смартфоні (iOS або Android)

### 2. Клонування репозиторію

```bash
git clone https://github.com/V1rtualChild/AICoach
cd aicoach
```

### 3. Встановлення залежностей

```bash
npm install
```

### 4. Створення `.env` файлу

```
EXPO_PUBLIC_GROQ_API_KEY=your_groq_api_key
```

> Отримати безкоштовний API ключ можна на: https://console.groq.com

### 5. Запуск

```bash
npx expo start
```

Відскануй QR-код у застосунку **Expo Go** на своєму смартфоні.

## API приклади

### Генерація тренування

**POST** `https://api.groq.com/openai/v1/chat/completions`

Request:
```json
{
  "model": "llama-3.3-70b-versatile",
  "messages": [
    {
      "role": "system",
      "content": "Ти персональний тренер. Профіль: вік 20, вага 70кг..."
    }
  ],
  "temperature": 0.7,
  "response_format": { "type": "json_object" }
}
```

Response:
```json
{
  "workout": {
    "title": "День 1: Тягові м'язи",
    "difficulty": "Середній",
    "duration": "45-60 хв",
    "exercises": [
      {
        "name": "Підтягування",
        "sets": "4",
        "reps": "10",
        "tips": "Тримай лопатки зведеними."
      }
    ]
  },
  "nutrition": {
    "meal_example": "Омлет з овочами — 3 яйця, болгарський перець 100г...",
    "advice": "Випий 500мл води одразу після тренування."
  }
}
```

### Аналіз харчування

**POST** `https://api.groq.com/openai/v1/chat/completions`

Request:
```json
{
  "model": "llama-3.3-70b-versatile",
  "messages": [
    { "role": "system", "content": "Ти спортивний дієтолог. Поверни JSON." },
    { "role": "user", "content": "Що я з'їв: гречка з куркою 300г" }
  ],
  "temperature": 0.1,
  "response_format": { "type": "json_object" }
}
```

Response:
```json
{
  "calories": 420,
  "protein": 38,
  "fats": 8,
  "carbs": 52,
  "name": "Гречка з куркою"
}
```

## Проблеми і рішення

| Проблема | Рішення |
|---|---|
| Помилка 401 Unauthorized від Groq API | Перевірити `EXPO_PUBLIC_GROQ_API_KEY` у файлі `.env` |
| Застосунок не запускається | Перевірити встановлення залежностей `npm install`, версію Node.js |
| Дані не зберігаються між сесіями | Перевірити коректність роботи AsyncStorage, не використовувати емулятор без підтримки storage |
| Groq API повертає не JSON | Перевірити наявність `response_format: { type: "json_object" }` у запиті |
| Expo Go не знаходить QR-код | Переконатись що телефон і комп'ютер в одній Wi-Fi мережі |
